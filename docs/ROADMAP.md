# Roadmap

Milestone labels are planning markers, never evidence claims. A feature remains non-working until it is `Machine verified` in [PARITY.md](PARITY.md).

| Release | Scope | Current status |
| --- | --- | --- |
| `0.1` | Protocol tools, simulator, and capture decoder | Planned |
| `0.2` | Read-only live-device communication | Planned |
| `0.3` | Electrically isolated pulse and output verification | Planned |
| `0.4` | LinuxCNC dry-motion integration | Planned |
| `1.0` | Complete parity matrix and machine acceptance | Planned |

Progress requires evidence, not calendar time. Each milestone must retain safety gates, exact-device scope, negative controls, and public-release hygiene.
